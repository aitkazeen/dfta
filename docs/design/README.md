# Handoff: Financer — экран валютной пары (4.3)

## Overview
Мобильный экран приложения Financer, показывающий котировку валютной пары (USD/KZT), свечной график с прогнозной зоной и карточку прогноза с индикаторами/новостями/точностью движка. Часть 1 из полного набора экранов брифа `financer-design-brief.md` — остальные экраны (главная/watchlist, полный прогноз, алерты, онбординг, уведомления и т.д.) будут добавляться отдельными файлами по мере готовности.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML** (Design Component формат внутреннего инструмента), а не production-код для копирования. Задача разработчика — **пересоздать этот дизайн в целевом окружении проекта** (React Native / Expo, согласно брифу) с использованием существующих паттернов кодовой базы. Если окружения ещё нет — выбрать наиболее подходящий стек (в брифе указано React Native / Expo).

`Financer - Pair Screen.dc.html` открывается напрямую в браузере для просмотра. Внутри — HTML/inline-CSS шаблон и небольшой JS-класс, управляющий состоянием (выбранный таймфрейм, открытые аккордеоны). Он статичный/фейковый: данные (курс, свечи, новости) — реалистичные заглушки, не живой API.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и структура компонентов взяты из дизайн-системы брифа (§3) и должны быть воспроизведены точно.

## Screen: Экран пары (USD/KZT)

### Purpose
Пользователь смотрит текущий курс, график и прогноз по конкретной паре; может сменить таймфрейм, развернуть индикаторы/новости/точность прогнозов, создать алерт (иконка-колокольчик).

### Layout
- Контейнер экрана: 393×852 (iPhone 15 Pro), тема — dark only.
- Вертикальный флекс: sticky-хедер сверху + скроллируемая область контента ниже (`overflow-y: auto`).
- Хедер (`position: sticky; top: 0`): паддинг `52px 16px 12px` (52px учитывает статус-бар устройства), нижняя граница `1px solid border/subtle`.
  - Строка навигации: back-chevron (36×36, круглая кнопка, `bg/surface-raised`) — заголовок "USD/KZT" (17/22, 600) — bell-кнопка (36×36, тот же стиль).
  - Курс: `display` стиль (40/44, 600, tabular-nums) "511.40 ₸" + бейдж дельты (↑ +0.6%, `signal/up` текст на `signal/up-bg` фоне, radius 8, padding 3px 8px).
  - Caption "Курс на 11:32 · обновляется каждые 15 мин" (11/15, 500, +0.3 tracking, `text/tertiary`).
  - Caption "НБ РК: 511.2 ₸ на 28.07" (тот же стиль).
- Контент (паддинг 16px по горизонтали):
  1. **Таймфрейм-табы**: 5 кнопок в ряд (1Ч/1Д/1Н/1М/1Г), flex:1 каждая, activного состояние — фон `accent/primary`, текст белый; неактивные — прозрачный фон, обводка `border/subtle`, текст `text/secondary`.

Прогнозный конус — `<polygon>` от точки последней цены (x=260) расширяющийся треугольником к правому краю (x=340) на диапазон 512–515 ₸; заливка `accent/primary` @ 14% opacity, обводка `accent/primary` пунктиром (`stroke-dasharray: 4 3`). ## Interactions & Behavior
- Таб таймфрейма — переключает активное состояние кнопки (визуально; смена данных графика в проде должна дёргать реальные данные за выбранный период).
- Аккордеоны — клик по хедеру секции тогглит развёрнутое состояние + анимация поворота шеврона (`transition: transform .15s`).
- Bell-иконка — переход к конструктору алерта, предзаполненному текущей парой (экран 4.6, не в этом пакете).
- Back-chevron — возврат на watchlist (4.2, не в этом пакете).
- "Подробнее" — переход на полный прогноз (4.4, не в этом пакете).
- Нет hover-состояний (мобильное приложение, touch-only). Все тапабельные зоны — минимум 36×36 в макете; в проде довести до 44×44 согласно брифу §3.3 (зона нажатия).

## State Management
- `timeframe: string` — текущий выбранный таймфрейм ('1Д' по умолчанию).
- `open: { indicators: bool, news: bool, accuracy: bool }` — состояние аккордеонов (indicators открыт по умолчанию).
- В проде добавить: данные котировки (live), массив свечей за выбранный таймфрейм, объект прогноза, список новостей, статистику точности — все с состояниями loading/error/empty (см. §6 брифа, не покрыты этим макетом).
