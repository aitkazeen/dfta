# Financer — дизайн-бриф для Claude Design

> **Как пользоваться:** скормить файл целиком. Затем просить экраны по одному: «Сделай экран 4.3 (Пара / график) в light и dark, iPhone 15 Pro». Дизайн-система (§3) обязательна к соблюдению во всех экранах — не изобретать новые токены.

---

## 1\. Продукт

**Financer** — мобильное приложение (iOS \+ Android, React Native / Expo), которое отвечает на один вопрос: **«что вероятно произойдёт с моей валютной парой в ближайшие сутки и почему».**

Ядро: технические индикаторы \+ сентимент новостей → прогноз направления с вероятностью → push-уведомление.

**Валюты MVP:** USD, EUR, RUB, KZT. **KZT — центральная валюта продукта**, базовые пары котируются только против неё: USD/KZT, EUR/KZT, RUB/KZT *(изменено 2026-08-07 — было 5 пар, включая USD/RUB и EUR/USD без KZT)*.

**Чем это НЕ является:** торговым терминалом, брокером, инвест-советником. Нет кнопок «купить/продать», нет портфеля, нет акций. Это критично и для юр. рисков, и для тона интерфейса.

### 1.1 Аудитория

Не трейдеры. Люди в Казахстане, России и СНГ, у которых валюта — бытовая тревога: сбережения, переводы родственникам, оплата зарубежных сервисов, покупка перед поездкой, зарплата в одной валюте — расходы в другой.

Три портрета:

| Портрет | Что нужно | Как влияет на дизайн |
| :---- | :---- | :---- |
| **Тревожный сберегатель** (35–55) | «Держать доллары или переложить?» Проверяет курс каждый день | Ответ должен читаться за 2 секунды на главном экране, без графиков |
| **Релокант / фрилансер** (25–40) | Ловит момент для конвертации, работает с 2–3 парами | Алерты по порогу, быстрый доступ к паре |
| **Любопытный полутрейдер** (25–45) | Хочет цифры, индикаторы, историю точности | Детали доступны, но убраны на второй уровень |

**Средний пользователь не знает, что такое RSI и ATR.** Термины допустимы только на «экспертном» уровне интерфейса и всегда с расшифровкой по тапу.

### 1.2 Главный дизайн-конфликт

Приложение должно одновременно:

- быть **понятным человеку, который путается в процентах**;  
- быть **честным**, не создавая ложной уверенности («85% рост» → человек несёт деньги в обменник);  
- выглядеть **компетентно**, иначе прогнозу не поверят.

Разрешение конфликта: **уверенность визуализируется как диапазон и всегда сопровождается фактической точностью движка.** Никогда не показываем одно голое число процентов крупным шрифтом без контекста.

## 2\. Принципы дизайна

1. **Ответ раньше данных.** Каждый экран открывается выводом («вероятен рост к 512–515 ₸»), а цифры и графики — подтверждением ниже. Не наоборот.  
2. **Честность как визуальный приём.** Неопределённость рисуется явно: диапазоны вместо точек, размытые края прогнозной зоны на графике, «точность движка: 61% за 90 дней» рядом с уверенностью.  
3. **Спокойный финансовый тон.** Тёмная база, приглушённые акценты, никакого неонового «казино». Красный и зелёный — узкими дозами, только для направления, никогда как заливка полэкрана.  
4. **Push — это продукт.** Уведомление проектируется как полноценный экран: пользователь должен получить ценность, не открывая приложение.  
5. **Плотность по уровням.** Уровень 1 — вывод. Уровень 2 — драйверы и график. Уровень 3 — индикаторы, история прогнозов, сырые новости. Никогда не всё сразу.  
6. **Ничего похожего на призыв к сделке.** Ни глаголов («покупай», «продавай», «действуй»), ни зелёных CTA-кнопок рядом с прогнозом, ни счётчиков «осталось N часов».

## 3\. Дизайн-система

### 3.1 Цвет

Тёмная тема — основная (финансовые приложения смотрят вечером и утром в постели). Светлая — обязательный паритет.

**Dark (primary)**

| Токен | HEX | Применение |
| :---- | :---- | :---- |
| `bg/base` | `#0B0F14` | Фон приложения |
| `bg/surface` | `#141A22` | Карточки, листы |
| `bg/surface-raised` | `#1C242E` | Модалки, поповеры, активные строки |
| `border/subtle` | `#26303B` | Разделители, обводка карточек |
| `text/primary` | `#EDF1F5` | Заголовки, значения |
| `text/secondary` | `#94A3B2` | Подписи, метаданные |
| `text/tertiary` | `#5D6B7A` | Дисклеймеры, таймстемпы |

**Light**

| :---- | :---- |

**Семантика (общая для тем)**

| Токен | HEX dark / light | Применение |
| :---- | :---- | :---- |
| `accent/primary` | `#4C8DFF` / `#2563EB` | Основной акцент, активные элементы, ссылки |
| `signal/up` | `#3DD68C` / `#0E9F6E` | Рост. Только текст, иконки, тонкие линии |

**Правило дальтонизма:** направление никогда не кодируется только цветом. Всегда цвет **\+ стрелка ↑/↓ \+ знак числа**.

### 3.2 Типографика

Шрифт: **Inter** (или системный SF Pro / Roboto). Цифры — **всегда табличные** (`font-variant-numeric: tabular-nums`), иначе курсы «дрожат» при обновлении.

| Стиль | Размер / межстрочный | Начертание | Применение |
| :---- | :---- | :---- | :---- |
| `display` | 40 / 44 | 600, tabular | Крупный курс на экране пары |
| `h1` | 28 / 34 | 600 | Заголовок экрана |
| `h2` | 20 / 26 | 600 | Заголовки секций |
| `title` | 17 / 22 | 600 | Заголовок карточки, строка пары |
| `body` | 15 / 22 | 400 | Основной текст, объяснение прогноза |
| `label` | 13 / 18 | 500 | Подписи, вкладки таймфреймов |
| `caption` | 11 / 15 | 500, \+0.3 трекинг | Таймстемпы, дисклеймеры, юр. текст |
| `mono-num` | 15 / 20 | 500, tabular | Значения в таблицах индикаторов |

### 3.3 Сетка, радиусы, тени

- Базовая единица **4**. Шкала: 4 / 8 / 12 / 16 / 24 / 32 / 48\.  
- Горизонтальные поля экрана — **16**. Внутренние поля карточки — **16**. Между карточками — **12**.  
- Радиусы: `sm 8` (бейджи, чипы) · `md 12` (кнопки, инпуты) · `lg 16` (карточки) · `xl 24` (bottom sheet) · `full` (аватар, пилюли).  
- Тени только в light-теме, мягкие: `0 1px 2px rgba(15,23,32,.06), 0 8px 24px rgba(15,23,32,.06)`. В dark-теме глубина — через `bg/surface-raised` и `border/subtle`, не через тени.  
- Минимальная зона нажатия — **44×44**.

### 3.4 Ключевые компоненты

Спроектировать как переиспользуемые, во всех состояниях.

**`DirectionBadge`** — пилюля: стрелка \+ слово \+ процент. Варианты `up` / `down` / `flat`, размеры `sm` (в списке) / `md` (в карточке).

**`ConfidenceMeter`** — горизонтальная шкала 0–100 с засечкой на 50 («случайность») и подписью-словом: `<55` \= «слабый сигнал», `55–65` \= «умеренный», `65–75` \= «выраженный», `>75` \= «сильный». **Слово важнее числа** — оно крупнее.

**`PairRow`** — строка watchlist: флаги-пара, тикер, текущий курс, дельта за 24ч, микро-спарклайн 7 дней, `DirectionBadge` `sm`. Высота 68\.

**`ForecastCard`** — главный носитель ценности. Структура сверху вниз: пара → направление и целевой диапазон крупно → `ConfidenceMeter` → 2–3 предложения объяснения → три драйвера-чипа → строка «Точность движка по этой паре: 61% (90 дней)» → `caption`\-дисклеймер.

**`DriverChip`** — иконка категории (📈 техника, 📰 новость, 🏛 регулятор — заменить на линейные иконки, не эмодзи) \+ короткий текст. Тапабельный, раскрывает источник.

**`CandleChart`** — свечи, переключатель таймфреймов (1Ч / 1Д / 1Н / 1М / 1Г), кросс-хэйр с плашкой значения, опциональные оверлеи EMA. Прогнозная зона справа от «сейчас» — **заштрихованный конус, растущий по ширине**, с пунктирной границей. Конус визуально не должен читаться как обещание.

**`NewsItem`** — источник \+ время, заголовок в 2 строки, метка тональности (точка \+ слово), бейдж «Влияет на USD/KZT».

**`AlertRuleCard`** — тип правила, условие человеческим языком («когда USD/KZT выше 510 ₸»), тумблер, тихие часы.

**`EmptyState`**, **`ErrorState`**, **`SkeletonLoader`** — обязательны, см. §6.

**`Disclaimer`** — `caption`, `text/tertiary`, всегда одинаковая формулировка (§7).

## 4\. Экраны

### 4.1 Онбординг (4 шага)

1. **Ценность.** «Курс, новости и вероятный прогноз — в одном уведомлении утром.» Иллюстрация: карточка прогноза в руке.  
2. **Выбор пар.** Сетка чипов валютных пар, минимум 1, рекомендованы 3\. Флаги \+ тикеры.  
3. **Разрешение на уведомления.** Пре-промпт **до** системного диалога: объяснить, что придёт ровно одно сообщение в день утром и что типы настраиваются. Кнопка «Не сейчас» — равноправна, не серая-незаметная.  
4. **Дисклеймер и ИИ.** Экран, а не мелкий чекбокс: информационный характер сервиса, часть текста генерируется ИИ, данные передаются третьим сторонам. Кнопка «Понятно» активна сразу, без скролл-ловушек.

Индикатор прогресса — точки. «Пропустить» доступен на шагах 1–3.

### 4.2 Главный / Watchlist

- Хедер: «Financer», справа — иконка настроек. Дата и время последнего обновления в `caption`.  
- **Верхняя карточка — «Сегодня»:** прогноз по паре №1 в сокращённом виде (направление \+ диапазон \+ одна строка объяснения). Это первое, что видит человек.  
- Далее список `PairRow`. Pull-to-refresh. Свайп по строке: закрепить / удалить.  
- FAB или строка внизу списка — «Добавить пару» → поиск.  
- Внизу — таб-бар: **Обзор · Новости · Алерты · Ещё**.

Показать в макете: 5 пар, одна с ростом, одна с падением, одна с боковиком.

### 4.3 Экран пары ⭐ (ключевой)

Скролл, четыре зоны:

1. **Шапка (sticky при скролле):** пара, текущий курс `display`, дельта за 24ч, время котировки, официальный курс ЦБ/НБ отдельной строкой `caption` («НБ РК: 511.2 ₸ на 28.07»).  
2. **График:** `CandleChart` на всю ширину, высота \~300. Таймфреймы. Прогнозный конус справа.  
3. **`ForecastCard`** — свёрнутый вариант с кнопкой «Подробнее» → 4.4.  
4. **Секции-аккордеоны:** «Индикаторы» (таблица: название, значение, интерпретация одним словом — «перекуплен», «нейтрально»), «Новости по паре» (3 штуки \+ «все»), «Точность прогнозов» (компактный график попаданий).

Сверху справа — иконка «колокольчик» для быстрого создания алерта по этой паре.

### 4.4 Прогноз (полный)

- Крупно: направление \+ целевой диапазон \+ горизонт (24ч / 7д — переключатель).  
- `ConfidenceMeter` с пояснением по тапу: что такое уверенность и как она посчитана.  
- Объяснение от ИИ — 2–3 предложения, с явной пометкой «сгенерировано ИИ» в `caption` под текстом.  
- **Три драйвера** развёрнутыми карточками: что произошло, как это влияет, ссылка на источник.  
- **Блок «Честная статистика»:** сколько прогнозов по паре сделано, сколько сбылось, график «предсказано vs. факт» за 90 дней. **Этот блок не прячем, даже когда точность низкая** — он и есть аргумент доверия.  
- Дисклеймер внизу.

### 4.5 Новости

- Фильтр-чипы сверху: «Все» \+ валюты \+ пары.  
- Список `NewsItem`, группировка по дням.  
- Важные новости (`impact_score` выше порога) — с левой цветной полосой `warn`.  
- Тап → bottom sheet: заголовок, краткое содержание, тональность, к каким парам относится, кнопка «Открыть источник» (внешний браузер).

### 4.6 Алерты

- Список `AlertRuleCard`, сгруппированный по паре.  
- «Создать алерт» → bottom sheet-конструктор: тип (порог / прогноз / резкое движение / важная новость) → пара → параметр → тихие часы. Формулировка правила собирается человеческим языком в реальном времени вверху шита.  
- Пустое состояние: объяснить 4 типа алертов карточками-примерами, а не пустым экраном.

### 4.7 Настройки уведомлений (отдельный экран, не подраздел)

- Мастер-тумблер \+ четыре независимых тумблера по типам.  
- Время утренней доставки — пикер, таймзона определяется автоматически с возможностью изменить.  
- Тихие часы — диапазон.  
- Лимит: «не более N уведомлений в день на пару» — слайдер.  
- **Тон экрана — «здесь ты главный».** Никаких тёмных паттернов, никаких предупреждений в духе «вы пропустите важное».

### 4.8 Ещё / Профиль

Аккаунт (Apple/Google), тема, язык (RU / KK / EN), «Как работает прогноз» (объясняющий экран), «Точность движка» (общая статистика), Юридическое (дисклеймер, приватность, раскрытие ИИ), «Источники данных», версия.

### 4.9 Дизайн уведомлений (обязательная часть макетов)

Отрисовать на locked screen iOS **и** Android:

| Тип | Заголовок | Текст |
| :---- | :---- | :---- |
| Ежедневный прогноз | `USD/KZT · прогноз на сегодня` | `Вероятен рост к 512–515 ₸. Умеренная уверенность. Драйвер: решение НБ РК по ставке.` |
| Порог | `USD/KZT пробил 510 ₸` | `Сейчас 510.4 ₸, +0.7% за сутки.` |
| Резкое движение | `RUB/KZT — аномальное движение` | `−1.8% за час, втрое выше обычной волатильности.` |
| Важная новость | `НБ РК повысил базовую ставку` | `Влияет на USD/KZT и RUB/KZT.` |

Показать группировку нескольких уведомлений в стопку и expanded-вид с текстом прогноза целиком.

## 5\. Пользовательские сценарии

1. **Утренняя проверка (60% использования):** push → тап → экран прогноза → закрыл. Весь сценарий — 8 секунд. Он должен работать идеально.  
2. **Первый запуск:** онбординг → выбор пар → разрешение на пуш → главный экран, уже заполненный данными (не пустой\!).  
3. **Ловля курса:** экран пары → колокольчик → порог → готово. Не более 4 тапов.  
4. **Разбор «почему»:** прогноз → драйвер → новость-источник → назад.

## 6\. Состояния и краевые случаи

Для каждого экрана обязательны макеты:

- **Загрузка** — скелетоны, повторяющие раскладку контента. Не спиннер по центру.  
- **Пусто** — watchlist без пар, новости без результатов фильтра, алерты без правил. Всегда с одним понятным действием.  
- **Ошибка сети** — данные из офлайн-кэша \+ плашка «Данные от 09:14, обновить». Приложение остаётся полезным офлайн.  
- **Провайдер недоступен** — курс есть (кэш), прогноза нет: карточка «Прогноз обновится, когда вернутся данные» вместо пустоты.  
- **Прогноз \= flat** — самый частый и самый скучный случай, а выглядеть должен нормально, а не как поломка. «Сильных сигналов нет, вероятен боковик 509–511 ₸».  
- **Низкая уверенность (\<55%)** — визуально приглушённая карточка, честная формулировка «сигнал слабый».  
- **Новая пара без истории** — прогноз недоступен, объяснить почему.  
- **Уведомления отключены системно** — ненавязчивая плашка на главном с кнопкой в системные настройки. Показывать не чаще раза в неделю.

## 7\. Юридические требования к интерфейсу

Не декоративны — на этом заворачивают релизы в App Review.

- **Никаких формулировок-рекомендаций.** Разрешено: «вероятное направление», «аналитический сигнал», «по данным модели». Запрещено: «покупайте», «выгодный момент», «стоит переложить».  
- **Нет кнопок сделки**, нет ссылок на брокеров и обменники, нет партнёрских виджетов конвертации.  
- **Дисклеймер** — на онбординге и на каждом экране прогноза. Единая формулировка: «Информационный сервис. Не является индивидуальной инвестиционной рекомендацией. Прошлые результаты не гарантируют будущих.»  
- **Раскрытие ИИ** — под каждым сгенерированным текстом пометка и отдельный экран с объяснением.  
- **Честная точность** — реальные цифры из статистики, а не маркетинговое число. Если движок ошибается — это видно в интерфейсе.

## 8\. Доступность и локализация

- Контраст текста ≥ 4.5:1, крупных значений ≥ 3:1 в обеих темах.  
- Поддержка Dynamic Type до 200%: карточки тянутся, ничего не обрезается. Проверить на `ForecastCard` — там больше всего текста.  
- Направление дублируется знаком и стрелкой, не только цветом.  
- VoiceOver: у графика — текстовое описание («USD/KZT, за неделю рост 1.2%, диапазон 505–511»).  
- Языки: RU (основной), KK, EN. **Казахский и русский длиннее английского на 20–30%** — заложить запас в кнопках, чипах и бейджах. Валюта: `511,20 ₸` — пробел-разделитель тысяч, запятая как десятичный разделитель для RU/KK.

**Данные в макетах — реалистичные, не lorem ipsum.** Курсы порядка USD/KZT ≈ 511, EUR/KZT ≈ 557, RUB/KZT ≈ 6.1. Заголовки новостей — правдоподобные для НБ РК, ЦБ РФ, ФРС.

**Три вещи, которые важнее остальных:**

1. `ForecastCard` — весь продукт умещается в одну карточку. Она должна быть убедительной и честной одновременно.  
2. Прогнозный конус на графике — визуальный язык неопределённости. Не должен читаться как линия-обещание.  
3. Ежедневное push-уведомление — единственный контакт с пользователем в дни, когда он не открывает приложение.
